Superstore sales performance

Sales, orders and customers for a US retailer from 2015 to 2018. Filter by region, category and time range to see what is driving the numbers.

About this project

What it answers

How are sales performing, how does that compare with the same months a year earlier, and which regions and product groups are behind the change?

The data

The Superstore sales dataset, a public sample dataset: 9,800 order lines from 4,922 orders across four US regions, January 2015 to December 2018. Each line has an order date, region, category, sub-category, customer and sales value. The file has no profit column, so the dashboard measures sales, orders and customers rather than profit or margin. “Last 12 months” means calendar year 2018.

How it works

  • The filters pick the order lines for the chosen range and for the same months one year earlier. Comparing with the same months removes the effect of seasonality, such as the November and December peak.
  • Sales is the sum of line values. Orders and customers are counted once each, using unique order and customer IDs. Average order value is sales divided by orders.
  • The summary sentence finds the sub-category with the largest sales increase and the largest decrease.
  • The chart, region bars and table are redrawn from the same filtered rows, so every number on the page agrees.

Built with

  • Python (pandas) to clean the data and convert it into a compact form embedded in the page
  • HTML and CSS (grid layout, light and dark themes, responsive down to phones)
  • JavaScript with no frameworks or chart libraries; charts are drawn as SVG
  • Instrument Sans from Google Fonts
  • Tested in headless Chromium with Playwright, on desktop and phone widths
  • Claude (AI assistant by Anthropic) for code and testing support
